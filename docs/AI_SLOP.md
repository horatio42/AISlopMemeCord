# The AI slop manifesto

> We were so preoccupied with whether we could, we did not stop to ask whether we should. We shipped it anyway.

## The premise

AISlopMemeCord is a chat platform built in the aesthetic of the last two years of the internet: neon gradients,
unread badges, fake headlines, copypasta, goblins, "this is the content I come here for." The name is not an apology.
It is a warning label and a design brief.

But the joke only works if the product actually works. A broken Discord clone with a funny README is not slop; it
is a demo. This thing has permission checks, transactions, CSRF, backups, tests and a mobile layout. The exterior is
unhinged. The interior is boring on purpose.

## The slop spectrum

| Layer | Slop level | Notes |
|---|---|---|
| Meme copy, headlines, toasts, empty states | Maximum | Intentionally unserious |
| Seed data, copypasta, fake arguments | Maximum | The demo server is a bit |
| Visual design | High | Neon, stickers, comic-sans energy, original SVG art |
| Feature naming | Medium | Slop Points, Slop Control, "touch grass" |
| API error messages | Medium | Funny text, stable machine-readable codes |
| Permissions, auth, crypto, storage | Zero | Boring, explicit, tested |
| Database and deployment | Negative | One SQLite file and one port |

If a future contributor makes the auth flow "funny", they have misunderstood the assignment.

## What "vibe-coded" means here

- The project was built by an AI coding agent working under human direction, with a human reviewing scope, design
  and acceptance.
- Code was generated quickly, then forced through typechecking, 85 integration tests, a production build, real
  browser smoke tests and a Docker run.
- Screenshots are generated by driving a real browser against a real seeded instance. They are not mockups.
- Subagents handled large UI surfaces (admin console, server settings) under explicit API contracts; integration,
  testing and documentation were centralized.
- The README is allowed to be proud of the process. The tests are not optional.

"Vibe-coded" is not a synonym for "unverified". It means the initial implementation came from intent and iteration
rather than a month of design documents.

## Slop principles

1. **The joke must not break the product.** A meme 404 should still be a 404 with a stable code.
2. **No dark patterns disguised as jokes.** No fake urgency, no engagement traps, no "share to unlock".
3. **Privacy is the straight man.** No telemetry, no external fonts, no "sign in with" a company.
4. **One container is a feature.** Every additional service is a chance for the deploy to fail.
5. **Local-first everything.** SQLite, uploads, search, memes, themes, sounds.
6. **Say the limitation out loud.** Especially E2EE and voice. Honesty is funnier than marketing.
7. **Tests are canon.** A feature that only exists in the README is lore, not software.
8. **No dead buttons.** If it renders, it does something or explains why it cannot.
9. **Boring where it counts.** Crypto, permissions, backups and migrations do not get joke implementations.
10. **Touch grass eventually.** The app should not be designed to maximize time inside it.

## Design constraints that are not jokes

- Single Bun process, one port, all state under `/data`.
- No runtime external services or outbound requests.
- Permission checks on the server for every resource action.
- Safe Markdown rendering without raw HTML.
- Argon2id passwords, hashed sessions, CSRF, origin checks, rate limits.
- Transactional multi-step writes and audit logs for moderation.
- Reproducible screenshots and a CI workflow that typechecks, tests, builds and builds the container.

## What we are not

- Not a serious competitor to Discord, Slack or Matrix.
- Not an audited security product.
- Not a bot platform or a marketplace.
- Not a promise of infinite scale.
- Not a place to put sensitive state secrets, even if the E2EE DMs are real.

## The contract

If you fork this: keep the tests, keep the privacy claims true, and do not make the permission model "more fun".
The slop belongs in the copy and the pixels. The rest should stay boring enough to trust.

If you are reading this at 3am: the app will still be here tomorrow. Close the tab. Touch grass. The slop will wait.
