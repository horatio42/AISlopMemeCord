# Screenshot gallery

All images are generated by driving a real seeded instance in Chromium. No mockups, no composited browser chrome.
Regenerate with:

```bash
bun run screenshot
```

The script boots a throwaway server on an ephemeral port, registers an admin and three extra users, connects two
browser clients to voice with fake media devices, and fails if the browser console logs an error or a key selector is
missing.
